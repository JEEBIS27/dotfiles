# Helix のキー体系

本文は「対象を選択 → 操作」。頻出の単語移動は単打を維持し、接頭辞を使う場合は「方向 → 対象」にする。
Super はデスクトップ、Alt は TUIOS、Ctrl はアプリ共通操作。

## Graphite の実キー

`files/helix/key-layout.nix` の `directionKeys = "haoe"` が、論理 h/j/k/l に対応する実キー。
`config.toml` は論理キーで記述し、Home Manager が全階層のキーマップを変換する。

| 論理キー | 実キー | 論理キー | 実キー |
| --- | --- | --- | --- |
| h/H | h/H | a/A | j/J |
| j/J | a/A | o/O | k/K |
| k/K | o/O | e/E | l/L |
| l/L | e/E | その他 | そのまま |

Shift だけなら変換する。Ctrl・Alt・Super・Meta を含むキーは変換しない。
接頭辞の後も入力ごとに判定する。Ctrl+E 自体はそのまま、離した後の方向指定は haoe。
挿入文字、検索欄、picker、補完、文字ジャンプの検索文字、置換文字、囲み文字は変換しない。

以下の表は論理キー。特に異なる実キーを併記する。

## 本文の基本

| 論理キー | Graphite 実キー | 操作 |
| --- | --- | --- |
| h/j/k/l | h/a/o/e | 左/下/上/右 |
| H/J/K/L | H/A/O/E | 各方向へ選択を伸ばす |
| w/e | w/l | 次/前の単語全体を選択 |
| W/E | W/L | 次/前の WORD 全体を選択 |
| b/B | b/B | 現在の単語/WORD の先頭へ移動 |
| i/I | i/I | 選択の前/後から入力 |
| o/O | k/K | 下/上に行を作って入力 |
| Enter/Shift+Enter | 同じ | 下/上に行を作って入力 |
| v | v | 文字単位の選択モード切替 |
| V | V | 行単位の選択モード開始。移動後も行全体を選択 |
| x/X | x/X | 現在行を選択し、繰り返すと下/上へ拡張 |
| a | j | ファイル全選択 |
| Esc | Esc | 通常モードへ戻り、カーソル位置へ選択を畳む |
| u/U | u/U | Undo/Redo |
| p/P | p/P | 選択の後/前に貼付け |
| / | / | 本文検索 |
| Space または : | 同じ | コマンド入力 |
| q/Q | q/Q | :write-quit / :quit!（保存して閉じる/変更を破棄して閉じる） |

w/e は単語選択、W/E は空白区切りの WORD 選択。選択モードではその方向に範囲を伸ばす。
b/B は現在の対象の先頭で止まり、既に先頭でも前の単語へは移らない。
以前の e/E の終端操作は廃止。選択後に I でそのまま後ろから入力できる。
例：wI は次の単語の後ろ、Wb は選択した WORD 内の現在の単語先頭、WB は WORD 先頭。
行頭/行末からの入力は gh→i / gl→I（実キー gh→i / ge→I）と合成する。
挿入モードの Space や文字キーは通常の文字入力。

## ヤンクの対立

| 小文字 | 操作 | 大文字 | 操作 |
| --- | --- | --- | --- |
| d | ヤンクせず削除 | D | 内部レジスターへカット |
| c | ヤンクせず削除し入力 | C | カットして入力 |
| r | 文字を置換 | R | 元の選択を内部ヤンクして置換 |
| y | 内部ヤンク | Y | 内部とシステムクリップボードへヤンク |

Delete は d と同じ。小文字は既存のヤンクを保持する。
r/R の次の入力は置換する文字。選択が囲みの境界なら、対応する囲みに置換する。
Ctrl+C/X/V は従来どおりシステムクリップボードを使う。

## 方向 → 対象

| 接頭辞 | 意味 |
| --- | --- |
| t | カーソルを含む対象を選択 |
| n | 次の対象 |
| N | 前の対象 |

| 対象キー | t（現在を含む） | n/N（次/前） |
| --- | --- | --- |
| w/W | 単語/WORD | 単語/WORD |
| f | 関数呼び出し全体 | 関数呼び出し全体 |
| F | 関数定義全体 | 関数定義全体 |
| p | 段落 | 段落へ移動 |
| m | 最も近い括弧・引用符の囲み全体 | — |
| (, [, {, 引用符など | 指定した種類の囲み全体 | — |
| / | — | 検索結果 |
| d | — | 診断 |
| c | — | 変更箇所 |
| b | — | バッファー |
| u | — | ジャンプ履歴 |
| s | — | 兄弟構文ノード |

例：SU|PER で tw は SUPER 全体。nf は次の呼び出し、NF は前の関数定義。
単打の w/e/W/E は nw/Nw/nW/NW の頻出ショートカット。
構文対象は Tree-sitter のノード種別から判断し、関数名の正規表現では探さない。
ネスト時の tf/tF はカーソルを含む最小の対象を選ぶ。n/N は開始位置の順に移動する。
呼び出しと定義のノードが対応している言語で使える。未対応・構文解析なし・該当対象なしの場合は選択を維持して通知する。

f/F 単独は次/前の指定文字まで選択するジャンプ。その後の検索文字はそのまま入力する。
到達点だけに畳む場合は ; を組み合わせる。
以前の「g → 対象 → 前/次」のメニューは廃止。

## 囲み：選択 → 操作

| 論理キー | 操作 |
| --- | --- |
| s → 囲み文字 | 選択をその文字のペアで囲む |
| sf → 関数名 → Enter | 選択を function(選択) の形で囲む |
| ts | 選択した囲み・呼び出し・波括弧の関数定義から、境界だけを選択 |
| ti | 同じ対象の内側だけを選択 |
| ts の後 d/D | 境界を削除/カットし、中身を残す |
| ts の後 r/R → 囲み文字 | 境界を新しいペアに置換（R は元の境界をヤンク） |
| ts の後 rf/Rf → 関数名 → Enter | 境界を関数呼び出しに置換 |

例：foo(a, b) 上で tf→ts→d は a, b。tf→ts→r[ は [a, b]。
tf→ti は引数部分だけ。t(→ts→d は括弧だけを取り除く。
関数定義の境界抽出は、波括弧の本体を持つ構文を対象とする。インデント形式の定義は tF で全体を選択できるが、ts での展開は行わない。
囲み入力中の Esc は取消。複数の置換は一回の Undo で戻る。

## 空間移動・選択管理

| 論理キー | Graphite 実キー | 操作 |
| --- | --- | --- |
| gh/gl | gh/ge | 行頭/行末 |
| gk/gj | go/ga | ファイル先頭/末尾（スムーズ移動） |
| G h/l/k/j | G h/e/o/a | 同じ位置まで選択を伸ばす |
| gK/gJ | gO/gA | 前/次の段落 |
| gm | gm | 対応する括弧へ |
| g v → k/j/m | g v → o/a/m | 画面の上/下/中央 |
| G/ | 同じ | 正規表現に合う部分を選択 |
| G バックスラッシュ | 同じ | 正規表現で選択を分割 |
| G; | 同じ | 選択のアンカーとカーソルを交換 |
| G, | 同じ | 主選択だけ残す |
| G- / G_ | 同じ | 選択を結合/前後の空白を除去 |

選択モードでは g も範囲を伸ばす。数値の回数指定は接頭辞の前に置く。

## アプリ共通操作

| キー | 操作 |
| --- | --- |
| Ctrl+S/W/N | 保存/ビューを閉じる/新規バッファー |
| Ctrl+C/X/V | クリップボードへコピー/カット/貼付け |
| Ctrl+Z / Ctrl+Shift+Z | Undo/Redo |
| Ctrl+A | 全選択 |
| Ctrl+F/B/D | ファイル/バッファー/変更ファイル一覧 |
| Ctrl+P | コマンド・割当キー検索。キーで探すなら %bindings x |
| Ctrl+/ | 行コメント切替 |
| Ctrl+H/J/K/L、Ctrl+矢印 | ビューを左/下/上/右へ |
| Ctrl+E → h/j/k/l | ビュー交換。離した後の実キーは h/a/o/e |
| Ctrl+Enter / Ctrl+Shift+Enter | 左右/上下分割 |
| Ctrl+PgUp/PgDown | 前/次のバッファー |
| Ctrl+T/Y | 永続フロート端末/Yazi |
| Ctrl+Shift+S | 通常・選択: ジャンプ履歴へ現在位置保存。挿入: Undo 区切り |
| Ctrl+Space | 挿入モードで補完 |
| Ctrl+Backspace/Delete | 挿入モードで前/次の単語を削除 |
| Ctrl+Shift+Delete | 挿入モードで行末まで削除 |

Ctrl+G の後に Ctrl を離す。論理 f/b/c: ファイル/バッファー/変更ファイル、s/S: ファイル/全体シンボル、d/D: 診断、g/G: 定義/宣言、r/i/t: 参照/実装/型、h: ホバー、a: コードアクション、j: ジャンプ履歴、/: 全体検索、p: パレット。
Graphite では最後の a/j を入れ替える。Ctrl+G 自体は変わらない。

Ctrl+Shift+G の後は、r: 名前変更、a: コードアクション、f: 整形、/: コメント、j: 行結合、i/u: インデント増減、c→l/u/t: 小文字/大文字/大小切替、n→e/w: 数値減増、p→r/c: ヤンク/クリップボードで置換、パイプ/!: シェル操作。
これらの修飾なしの後続キーにも同じ配列変換を適用する。

Ctrl+G→u は拡張メニュー。f/F: Flash 前後、r: 最近のファイル、p: 探索、z/m: ズーム/中央、n: 通知、t/T/s/h/q: 端末切替/追加/選択/非表示/終了、b/B: バッファーライン有効/無効。
埋め込み端末内は fish のキー規則。Ctrl+T で非表示/再表示、Ctrl+Esc で clear。

## 表示とスクロール

相対行番号と現在行の背景を有効にする。通常・選択モードはブロック、挿入モードは縦線。
カーソル色は通常 accent、挿入 green、選択 magenta。
現在行は lighter_background、選択は background と accent の混色（主選択45%、その他35%）。
テーマ管理元は files/desktop/templates/helix.toml.tpl。モード色は Steel の OSC 12、終了時はラッパーの OSC 112 で戻す。

PgUp/PgDown は本文の半画面分を約140ms・10フレームで移動する。
gk/gj と Gk/Gj も同じ時間でファイル先頭/末尾へ移動する。別キーを受けたら目的地へ到達してから処理する。
ジャンプ履歴にアニメーション途中の位置を残さない。

## 予約キーと管理元

論理 A、T、S、m、z/Z などは単打で未割当。e/E は前の単語/WORD、b/B は単語/WORD 先頭として使用する。
管理元は files/helix/config.toml、配列は files/helix/key-layout.nix、カスタム操作は files/helix/steel/init.scm。
一覧を変えるときは論理キーを編集し、Home Manager の生成結果を通常の hx に反映する。

検索窓・picker・補完・拡張 UI は本文と別のキーマップ。矢印で候補移動、Enter で確定、Esc で取消。
Tab/Shift+Tab でも候補を前後できる。本体に固定された Ctrl+N/P などの別名は本文設定では変更しない。

## 検証

`python scripts/check-helix-keys.py` は論理キーで既存操作を確認する（pyte が必要）。
生成した config.toml は `python scripts/check-helix-reform.py --config /path/to/config.toml` で検証する。
通常の hx と実際の設定で確認する場合は `--live`、対象を絞る場合は `--match` を付ける。
`--live` 以外ではクリップボードも一時ファイルに分離する。
