# Helix のキー体系

Vim 互換より、PC 全体のレイヤー分担と方向の一貫性を優先する。
Super はデスクトップ、Alt は TUIOS、Ctrl はアプリ操作。
本文編集は「対象 → 操作」でまとめ、頻度の高い対象ほど入力を短くする。
空間の方向は h/j/k/l、順序だけの前後は b/w に分ける。

## 本文の基本

| キー | 操作 |
| --- | --- |
| h / j / k / l、矢印 | 左 / 下 / 上 / 右 |
| b / w | 前 / 次の単語を選択（g b / g w と同じ） |
| B / W | 前 / 次の WORD を選択（g B / g W と同じ） |
| e / E | 選択済みなら対象の終端。単独なら単語 / WORD の終端 |
| H / J / K / L | 選択範囲を左 / 下 / 上 / 右へ伸ばす |
| g | 移動プレフィックス |
| G | 同じ対象へ選択を伸ばすプレフィックス |
| v | 選択モード切替。選択モードでは g も範囲を伸ばす |
| Esc | ノーマルモードに戻り、選択をカーソル位置へ畳む |
| i / a | 選択の前 / 後から入力 |
| I / A | 行頭 / 行末から入力 |
| Enter / Shift+Enter | 下 / 上に行を作って入力 |
| Delete、d | ヤンク内容を変えず選択を削除 |
| c | ヤンク内容を変えず選択を削除して入力 |
| r | 選択の文字を指定文字に置換 |
| u / U | Undo / Redo（Ctrl+Z / Ctrl+Shift+Z も有効） |
| y / p / P | 内部レジスターへコピー / 後 / 前に貼付け |
| / | 本文検索を開始 |
| : | コマンド入力 |

`g w` は g を離してから w。`G w` は Shift+G を離してから w。
空間を持つ移動には h/j/k/l と矢印を使う。
単語・検索結果・履歴などの前後は b/w、先頭/末尾を用意した一覧では B/W を使う。
入力モードの文字キーは文字入力のまま。

## 移動と範囲選択

| 移動 | 選択拡張 | 対象・方向 |
| --- | --- | --- |
| g b / g w | G b / G w | 前 / 次の単語を選択 / 範囲を拡張 |
| g B / g W | G B / G W | 前 / 次の WORD を選択 / 範囲を拡張 |
| g k / g j | G k / G j | ファイル先頭 / 末尾 |
| g h / g l | G h / G l | 行頭 / 行末 |
| g K / g J | G K / G J | 前 / 次の段落 |
| g a → h / l | G a → h / l | 行頭 / 行末 |
| g a → k / j | G a → k / j | 論理行を上 / 下へ |
| g r → b / w | G r → b / w | 前 / 次の検索結果 |
| g o f → b / w | G o f → b / w | 前 / 次の関数 |
| g o c → b / w | G o c → b / w | 前 / 次のクラス |
| g o a → b / w | G o a → b / w | 前 / 次の引数 |
| g o m → b / w | G o m → b / w | 前 / 次のコメント |
| g o t → b / w | G o t → b / w | 前 / 次のテスト |
| g o x → b / w | G o x → b / w | 前 / 次の XML 要素 |

単語・WORD の移動は対象全体を選択する。終端への移動は独立した e/E で合成する。
`we` は次の単語を選んで終端へ、`Be` は前の WORD を選んで終端へ移る。
選択済みの対象を優先するので、`We` と `WE` は同じ結果。`wE` でも単語から WORD へ広げない。
選択のないカーソルから単独で使う場合に、e は単語、E は WORD を対象とする。
構文対象は対象の範囲を選ぶ。`G` は元のアンカーから範囲を伸ばす。
選択モードの `g` / `G` は選択モードを維持する。
`3 g w` のように、プレフィックスの前に回数を指定できる。

| キー | 操作 |
| --- | --- |
| g d → b / w | 前 / 次の診断 |
| g c → b / w | 前 / 次の変更箇所 |
| g f → b / w | 前 / 次のバッファー |
| g u → b / w | ジャンプ履歴を戻る / 進む |
| g v → k / j / m | 画面内の上 / 下 / 中央へ |
| g m | 対応する括弧へ |

`g d` と `g c` の後は B で最初、W で最後の対象へ移動する。
診断は診断範囲を選ぶ操作であり、任意のアンカーからの拡張にはしない。
バッファー・ジャンプ履歴・画面位置の移動にも G 版は設けない。

## 構文と選択の管理

| キー | 操作 |
| --- | --- |
| g s / G s → b / w | 前 / 次の兄弟ノードを選択 |
| g s / G s → k / j | 親へ拡大 / 子へ縮小 |
| g s / G s → a / c | 兄弟をすべて / 子をすべて選択 |
| g s → h / l | 親ノードの始端 / 終端 |
| G s → h / l | 親ノードの始端 / 終端まで拡張 |
| G Space | 全選択 |
| G x / G X | 行を選択し、下 / 上へ拡張 |
| G / | 正規表現に合う部分を選択 |
| G バックスラッシュ | 正規表現で選択を分割 |
| G ; | 選択のアンカーとカーソルを交換 |
| G , | 主選択のみ残す |
| G - | 選択を結合 |
| G _ | 選択の前後の空白を除去 |

## アプリ共通操作

| キー | 操作 |
| --- | --- |
| Ctrl+S / Ctrl+W / Ctrl+N | 保存 / ビューを閉じる / 新規バッファー |
| Ctrl+C / Ctrl+X / Ctrl+V | システムクリップボードへコピー / カット / 貼付け |
| Ctrl+Z / Ctrl+Shift+Z | Undo / Redo |
| Ctrl+A | 全選択 |
| Ctrl+F / Ctrl+B / Ctrl+D | ファイル / バッファー / 変更ファイルの一覧 |
| Ctrl+P | コマンドパレット |
| Ctrl+/ | 行コメント切替 |
| Ctrl+H/J/K/L、Ctrl+矢印 | ビューを左 / 下 / 上 / 右へ移動 |
| Ctrl+E → h/j/k/l、矢印 | ビューを指定方向へ交換 |
| Ctrl+Enter / Ctrl+Shift+Enter | 左右 / 上下分割 |
| Ctrl+PageUp / Ctrl+PageDown | 前 / 次のバッファー |
| Ctrl+T / Ctrl+Y | 永続フロート端末 / Yazi |
| Ctrl+Shift+S | ノーマル・選択モード: ジャンプ履歴へ現在位置を保存。入力モード: Undo 区切り |
| Ctrl+Space | 入力モードで補完を開く |
| Ctrl+Backspace / Ctrl+Delete | 入力モードで前 / 次の単語を削除 |
| Ctrl+Shift+Delete | 入力モードで行末まで削除 |

Ctrl+G を押したあとに Ctrl を離し、以下のキーを押す。

| Ctrl+G → | 探索・一覧 |
| --- | --- |
| / | 全体検索（旧 Ctrl+G） |
| f / b / c | ファイル / バッファー / 変更ファイル |
| s / S | ファイル / ワークスペースのシンボル |
| d / D | ファイル / ワークスペースの診断 |
| j | ジャンプ履歴 |
| g / G | 定義 / 宣言 |
| r / i / t | 参照 / 実装 / 型定義 |
| h | ホバー情報 |
| a | コードアクション |
| p | コマンドパレット |
| u | 拡張メニュー（旧 Space u） |

拡張メニューは f/F: Flash 前方/後方、r: 最近のファイル、p: 探索、
z/m: ズーム/中央寄せ、n: 通知、t/T/s/h/q: 端末の切替/追加/選択/非表示/終了、
b/B: バッファーラインの有効/無効。入力モードからも呼び出せる。

## 適用範囲と既定キー

管理元は `files/helix/config.toml`、拡張メニューは `files/helix/steel/init.scm`。
単独 w/b は単語、W/B は WORD の前後へ統一し、e/E で終端操作を合成する。旧 n/N、角括弧、Space、z/Z のメニューなどは無効化する。
既定の g メニューも、旧 n/p などの方向別名が残らないよう明示的に無効化する。
使わない機能は Ctrl+P またはコマンド入力から探せる。

検索窓・picker・補完候補・拡張の独自 UI は本文キーマップと別実装。
これらの入力欄では文字を入力し、候補の移動は上下矢印、確定は Enter、取消は Esc を基本とする。
picker/補完候補では Tab/Shift+Tab も次/前の候補に使える。
本体に固定された Ctrl+N/P などの別名までは、この設定で変更できない。
本文用 g/G や Ctrl+H/J/K/L が入力欄でも同じ動作をするとは扱わない。
Alt は TUIOS のために空ける。埋め込み端末内は fish のキー規則を使う。

## 表示

相対行番号と現在行の背景を有効にする。通常・選択モードはブロック、挿入モードは縦線。
カーソルは通常がパレットの accent、挿入が green、選択が magenta。
縦線は端末が描画するため、Steel のモードフックで OSC 12 により同じパレット色を指定する。
Helix 終了時は待機ラッパーが OSC 112 で端末既定のカーソル色へ戻す。
現在行は lighter_background を使い、選択範囲の背景とは区別する。
設定元は files/desktop/templates/helix.toml.tpl なので、テーマ切替後も色の役割を保つ。
