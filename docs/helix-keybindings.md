# Helix のキー体系

本文は「対象を選択 → 操作」。頻出の単語移動は単打を維持し、接頭辞を使う場合は「方向 → 対象」にする。
Super はデスクトップ、Alt は TUIOS、Ctrl はアプリ共通操作。

## Graphite の実キー

`files/helix/key-layout.nix` の `directionKeys = "haoe"` が、論理 h/j/k/l に対応する実キー。
`config.toml` は論理キーで記述し、Home Manager が全階層のキーマップを変換する。

| 論理キー | 実キー | 論理キー | 実キー |
| --- | --- | --- | --- |
| h/H | h/H | a/A | j/J |
| j/J | a/A | o/O | k/K |
| k/K | o/O | e/E | l/L |
| l/L | e/E | その他 | そのまま |

Shift だけなら変換する。Ctrl・Alt・Super・Meta を含むキーは変換しない。
接頭辞の後も入力ごとに判定する。Ctrl+E 自体はそのまま、離した後の方向指定は haoe。
挿入文字、検索欄、picker、補完、文字ジャンプの検索文字、置換文字、囲み文字は変換しない。

以下の表は論理キー。特に異なる実キーを併記する。

## 本文の基本

| 論理キー | Graphite 実キー | 操作 |
| --- | --- | --- |
| h/j/k/l | h/a/o/e | 左/下/上/右 |
| H/J/K/L | H/A/O/E | 各方向へ選択を伸ばす |
| w/e | w/l | 次/前の単語全体を選択 |
| W/E | W/L | 次/前の WORD 全体を選択 |
| b/B | b/B | 現在の単語/WORD の先頭へ移動 |
| i/I | i/I | 選択の前/後から入力 |
| o/O | k/K | 各文字の大小反転 / 全大文字→全小文字→先頭だけ大文字 |
| Enter/Shift+Enter | 同じ | 下/上に行を作って入力 |
| v | v | 文字単位の選択モード切替 |
| V | V | 行単位の選択モード開始。移動後も行全体を選択 |
| x/X | x/X | 現在行を選択し、繰り返すと下/上へ拡張 |
| Ctrl+A | Ctrl+A | ファイル全選択 |
| Esc | Esc | 通常モードへ戻り、カーソル位置へ選択を畳む |
| u/U | u/U | Undo/Redo |
| t/T | t/T | 選択対象を一段階拡大/縮小 |
| s/S | s/S | 最も近い囲みの境界/内側だけを選択 |
| z/Z | z/Z | カーソル上・同じ行の右側の値を増加/減少 |
| `>` / `<` | 同じ | 選択範囲の行をインデント増加/減少 |
| p/P | p/P | 選択の後/前に貼付け |
| / | / | 本文検索 |
| Space または : | 同じ | コマンド入力 |
| q/Q | q/Q | :write-quit / :quit!（保存して閉じる/変更を破棄して閉じる） |

w/e は単語選択、W/E は空白区切りの WORD 選択。選択モードではその方向に範囲を伸ばす。
b/B は現在の対象の先頭で止まり、既に先頭でも前の単語へは移らない。
以前の e/E の終端操作は廃止。選択後に I でそのまま後ろから入力できる。
例：wI は次の単語の後ろ、Wb は選択した WORD 内の現在の単語先頭、WB は WORD 先頭。
行頭/行末からの入力は gh→i / gl→I（実キー gh→i / ge→I）と合成する。
挿入モードの Space や文字キーは通常の文字入力。

## ヤンクの対立

| 小文字 | 操作 | 大文字 | 操作 |
| --- | --- | --- | --- |
| d | ヤンクせず削除 | D | 内部レジスターへカット |
| c | ヤンクせず削除し入力 | C | カットして入力 |
| r | 文字を置換 | R | 元の選択を内部ヤンクして置換 |
| y | 内部ヤンク | Y | 内部とシステムクリップボードへヤンク |

Delete は d と同じ。小文字は既存のヤンクを保持する。
r/R の次の入力は置換する文字。選択が囲みの境界なら、対応する囲みに置換する。
Ctrl+C/X/V は従来どおりシステムクリップボードを使う。

## 対象選択：t/T/s/S

最初の t はカーソルを含む単語を即座に選ぶ。待ち時間や確定キーは不要。
続けて t は一段階大きく、T は一段階小さくする。基本候補は文字・単語・WORD・行・段落・ファイル。
それらにカーソルを含む囲み全体を加え、現在の対象全体を含む最小の大きい候補へ進む。
同じ範囲は飛ばす。複数行の囲みを収められない行など、包含関係にない候補も飛ばす。
例：foo(ba|r) は t で bar、さらに t で (bar)、さらに t で foo(bar)。T は逆順。
縮小時も選択開始位置を保持するので、複数の引数があっても対象がぶれない。最小の文字はUnicodeの書記素単位。

| キー | 選択する部分 |
| --- | --- |
| s | 最も近い囲みの境界だけ |
| S | 同じ囲みの内側だけ |
| s の後 S / S の後 s | 同じ囲みの境界/内側へ切替 |
| その後 t/T | 境界/内側の選び方を保って、一段階外側/内側の囲みへ |

s/S 自体の連打で階層は変わらない。境界/内側を扱う間の t/T は、囲みを持つ候補だけをたどる。
s の境界選択後にカーソル移動すると、境界の複数選択を解除して元のカーソル位置から移動する。
初回の s/S は文字を変更しない。囲みが見つからなければ元の選択を保つ。

t/T/s/S の後に (, [, {, 引用符などを押すと、現在の対象を含む、その種類の囲みへ移る。
同じ記号の繰り返しはさらに外側へ進む。t で始めた場合は全体、s は境界、S は内側という選び方を維持する。
対応する囲みがなければ選択を保つ。

tf/tF は明示的な関数呼び出し/定義の選択として残す。tm は囲み全体の明示選択。
関数の選択は Tree-sitter を使い、ネスト時は開始カーソルを含む最小の対象を選ぶ。
対応する構文解析がない場合は元の選択を保つ。関数定義から境界/内側を抽出できるのは、波括弧の本体を持つ構文。

ここまでのキーは選択専用。d/c/r/y/i/I/p、移動、Ctrlショートカットなどを押すと、今の選択へ通常の操作を行い、選択継続を終了する。
`>` / `<` は選択後もインデント増加/減少として実行し、囲みの継続指定には使わない。
Esc は通常どおり選択をカーソル位置へ畳む。挿入文字、置換文字、検索欄、picker、端末では継続キーを解釈しない。

## 囲みの操作

| 選択後の操作 | 結果 |
| --- | --- |
| s → d/D | 境界を削除/カットし、中身を残す |
| S → c/C | 囲みを残し、中身を削除/カットして入力 |
| s → r/R → 新しい囲み文字 | 境界を新しいペアへ置換（R は元の境界をヤンク） |
| s → rf/Rf → 関数名 → Enter | 境界を関数呼び出しへ置換 |
| Ctrl+Shift+G → s → a → 囲み文字 | 選択に囲みを追加 |
| Ctrl+Shift+G → s → a → f → 関数名 → Enter | 選択を function(選択) で囲む |

追加操作の a は論理キーなので、Graphite の実入力は Ctrl+Shift+G → s → j。
例：foo(a, b) 上で tf→s→d は a, b。tf→s→r[ は [a, b]。tf→S は引数部分だけ。
囲み入力中の Esc は取消。複数箇所の囲み置換も一回の Undo で戻す。

## スマートな増減：z/Z

z は増加、Z は減少。カーソル上、または同じ行の右側にある最初の値を選んで変更する。
例：val|ue = 20 で Z は value = 19。左側や次の行の値は変更しない。
整数は Helix 標準処理を使い、負数・桁区切り・0x/0o/0b 表記を保つ。
true/false、True/False、TRUE/FALSE は boolswitcher.hx の変換処理で切り替える。
0/1 は真偽値として扱わず、通常の整数として増減する。3z/3Z は3増減、真偽値は奇数回で反転・偶数回で維持。
対象全体が選択されるので、そのまま再操作できる。複数カーソルではそれぞれの位置から探し、重複する対象は一回だけ変更する。
識別子中の数字や trueValue は対象外。小数は桁数を保って値を1増減する（1.25→2.25、0.25→-0.75）。小数の指数表記は通常の小数表記へ変換する。
YYYY-MM-DD / YYYY/MM/DD、HH:MM[:SS] も標準処理を使う（日付は日、時刻は分）。
ヤンクとクリップボードは変更しない。一回の操作は一回の Undo で戻す。
z/Z は「値を選択→増減」をまとめたショートカット。選択済みの値へ標準処理だけを使う Ctrl+Shift+G→n→w/e も維持する。
boolswitcher は packages/helix-steel/sources.json に固定した版を使う。右側の対象を探す処理だけを独自に追加している。

## 方向 → 対象

n/N は次/前の対象。単打 w/e/W/E は nw/Nw/nW/NW の頻出ショートカット。

| 対象キー | n/N の対象 |
| --- | --- |
| w/W | 単語/WORD |
| f/F | 関数呼び出し/定義 |
| p | 段落 |
| / | 検索結果 |
| d/c | 診断/変更箇所 |
| b/u | バッファー/ジャンプ履歴 |
| s | 兄弟構文ノード |

f/F 単独は次/前の指定文字まで選択するジャンプ。検索文字は配列変換しない。
到達点だけに畳む場合は ; を組み合わせる。

## 空間移動・選択管理

| 論理キー | Graphite 実キー | 操作 |
| --- | --- | --- |
| gh/gl | gh/ge | 行頭/行末 |
| gk/gj | go/ga | ファイル先頭/末尾（スムーズ移動） |
| G h/l/k/j | G h/e/o/a | 同じ位置まで選択を伸ばす |
| gK/gJ | gO/gA | 前/次の段落 |
| gm | gm | 対応する括弧へ |
| g v → k/j/m | g v → o/a/m | 画面の上/下/中央 |
| G/ | 同じ | 正規表現に合う部分を選択 |
| G バックスラッシュ | 同じ | 正規表現で選択を分割 |
| G; | 同じ | 選択のアンカーとカーソルを交換 |
| G, | 同じ | 主選択だけ残す |
| G- / G_ | 同じ | 選択を結合/前後の空白を除去 |

選択モードでは g も範囲を伸ばす。数値の回数指定は接頭辞の前に置く。

| Ctrl+/ | 行コメント切替 |
| Ctrl+H/J/K/L、Ctrl+矢印 | ビューを左/下/上/右へ |
| Ctrl+E → h/j/k/l | ビュー交換。離した後の実キーは h/a/o/e |
| Ctrl+Enter / Ctrl+Shift+Enter | 左右/上下分割 |
| Ctrl+PgUp/PgDown | 前/次のバッファー |
| Ctrl+T/Y | 永続フロート端末/Yazi |
| Ctrl+Shift+S | 通常・選択: ジャンプ履歴へ現在位置保存。挿入: Undo 区切り |
| Ctrl+Space | 挿入モードで補完 |
| Ctrl+Backspace/Delete | 挿入モードで前/次の単語を削除 |
| Ctrl+Shift+Delete | 挿入モードで行末まで削除 |

Ctrl+G の後に Ctrl を離す。論理 f/b/c: ファイル/バッファー/変更ファイル、s/S: ファイル/全体シンボル、d/D: 診断、g/G: 定義/宣言、r/i/t: 参照/実装/型、h: ホバー、a: コードアクション、j: ジャンプ履歴、/: 全体検索、p: パレット。
Graphite では最後の a/j を入れ替える。Ctrl+G 自体は変わらない。

Ctrl+Shift+G の後は、r: 名前変更、a: コードアクション、f: 整形、/: コメント、j: 行結合、i/u: インデント増減、c→l/u/t: 小文字/大文字/大小切替、n→e/w: 数値減増、p→r/c: ヤンク/クリップボードで置換、パイプ/!: シェル操作。
これらの修飾なしの後続キーにも同じ配列変換を適用する。

Ctrl+G→u は拡張メニュー。f/F: Flash 前後、r: 最近のファイル、p: 探索、z/m: ズーム/中央、n: 通知、t/T/s/h/q: 端末切替/追加/選択/非表示/終了、b/B: バッファーライン有効/無効。
埋め込み端末内は fish のキー規則。Ctrl+T で非表示/再表示、Ctrl+Esc で clear。

## 表示とスクロール

相対行番号と現在行の背景を有効にする。通常・選択モードはブロック、挿入モードは縦線。
カーソル色は通常 accent、挿入 green、選択 magenta。
現在行は lighter_background、選択は background と accent の混色（主選択45%、その他35%）。
テーマ管理元は files/desktop/templates/helix.toml.tpl。モード色は Steel の OSC 12、終了時はラッパーの OSC 112 で戻す。

PgUp/PgDown は本文の半画面分を約140ms・10フレームで移動する。
gk/gj と Gk/Gj も同じ時間でファイル先頭/末尾へ移動する。別キーを受けたら目的地へ到達してから処理する。
ジャンプ履歴にアニメーション途中の位置を残さない。

## 予約キーと管理元

論理 A、m は単打で未割当。e/E は前の単語/WORD、b/B は単語/WORD 先頭として使用する。
管理元は files/helix/config.toml、配列は files/helix/key-layout.nix、カスタム操作は files/helix/steel/init.scm。
一覧を変えるときは論理キーを編集し、Home Manager の生成結果を通常の hx に反映する。

検索窓・picker・補完・拡張 UI は本文と別のキーマップ。矢印で候補移動、Enter で確定、Esc で取消。
Tab/Shift+Tab でも候補を前後できる。本体に固定された Ctrl+N/P などの別名は本文設定では変更しない。

## 検証

`python scripts/check-helix-keys.py` は論理キーで既存操作を確認する（pyte が必要）。
生成した config.toml は `python scripts/check-helix-reform.py --config /path/to/config.toml` で検証する。
通常の hx と実際の設定で確認する場合は `--live`、対象を絞る場合は `--match` を付ける。
`--live` 以外ではクリップボードも一時ファイルに分離する。依存ソースの配置前は `--boolswitcher /path/to/source` を指定できる。

## 大小文字：o/O

論理 o（Graphite k）は各文字の大文字・小文字を反転する。LaTeX→lAtEx→LaTeX。
論理 O（Graphite K）は選択全体を LATEX→latex→Latex→LATEX と循環させる。混在表記からはまず全大文字にする。複数選択では各範囲を別々に処理する。
