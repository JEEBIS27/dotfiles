# Theme button dependencies

Single click opens the built-in Omarchy theme picker. Double click opens Aether.

Aether: https://github.com/omacom/aether/releases/tag/v4.32.0
Binary: https://github.com/omacom/aether/releases/download/v4.32.0/aether-linux-amd64
Install path: ~/.local/bin/aether
SHA-256: c705a4abef734b17ae37cdbff58a9a796517e6aa5f93ef18b68e3ee99d547ff9
Arch dependency: webkit2gtk-4.1

The binary is installed separately and is not stored in chezmoi.
Workspace previews are supplied by the locally adapted jeebis.overview plugin;
see that plugin's LOCAL-CHANGES.md for upstream provenance and compatibility edits.
